# Курсова робота: Кібернетичні принципи управління в нейронних мережах

**Тема:** Аналіз зворотного поширення помилки (Backpropagation) крізь призму кібернетичних принципів управління.
**Автор:** Дмитро Мартиненко (Група ТК-31)

## Опис проєкту
Цей репозиторій містить програмну реалізацію курсової роботи, присвяченої дослідженню нейронних мереж як кібернетичних систем управління. Основний фокус зосереджено на аналізі алгоритму зворотного поширення помилки (Backpropagation). Проєкт реалізує повний цикл роботи з нейронною мережею: від генерації даних та побудови архітектури моделі до проведення експериментів з різними гіперпараметрами та візуалізації результатів. Код структуровано з дотриманням принципів чистої архітектури.

## Структура репозиторію
Проєкт розділено на логічні модулі для зручності підтримки та масштабування:

* `main.py` — головний скрипт, що ініціалізує та запускає весь процес моделювання.
* `config.py` — файл із конфігураційними параметрами мережі та експериментів.
* `data_generator.py` — модуль для створення синтетичних наборів даних, необхідних для навчання та тестування.
* `model.py` — реалізація архітектури нейронної мережі (пряме поширення, функції активації).
* `training.py` — логіка навчання моделі, включаючи алгоритм зворотного поширення помилки та оновлення ваг.
* `experiments.py` — скрипт для проведення різних сценаріїв навчання (наприклад, з різною швидкістю навчання: збалансованою, повільною, великою).
* `visualization.py` — набір функцій для побудови графіків та візуалізації роботи кібернетичної системи.
* `requirements.txt` — список необхідних Python-бібліотек для запуску проєкту.
* `data/` — директорія для збереження проміжних або вхідних даних.
* `results/` — директорія, куди автоматично зберігаються результати експериментів (CSV файли та графіки).

## Результати та візуалізація
У процесі виконання `main.py`, в папці `results/` генеруються такі артефакти:

* **Дані:** `dataset.csv`, `training_history.csv`, `summary_results.csv`.
* **Графіки процесу навчання:** `loss_curves.png`, `accuracy_curves.png`, `final_loss.png`, `final_accuracy.png`.
* **Внутрішні кібернетичні процеси:** `gradient_norms.png`, `weight_updates.png`, `cybernetic_loop.png`, `network_architecture.png`.
* **Поверхні прийняття рішень:** `decision_boundary_balanced.png`, `decision_boundary_slow.png`, `decision_boundary_large_lr.png`.

## Як запустити проєкт

**1. Клонуйте репозиторій:**
```bash
git clone [https://github.com/ВАШ_ЮЗЕРНЕЙМ/martynenko_nn_control.git](https://github.com/ВАШ_ЮЗЕРНЕЙМ/martynenko_nn_control.git)
cd martynenko_nn_control
```

**2. Встановіть залежності:**
Рекомендується використовувати віртуальне середовище (venv).
```bash
pip install -r requirements.txt
```

**3. Запустіть експерименти:**
```bash
python main.py
```

Після успішного виконання скрипта, перевірте папку `results/` для перегляду згенерованих звітів, графіків та наборів даних.
